# 📚 Book4U
맞춤형 도서 추천 서비스

<br>

# 🎯 프로젝트 개요 (About)
Book4U는 사용자의 취향과 행동을 바탕으로 AI를 활용하여 맞춤형 도서를 추천하는 서비스입니다.<br/>
베스트셀러, 개인화 추천, AI 추천, 주변 서점 검색 등 다양한 기능을 제공합니다.
